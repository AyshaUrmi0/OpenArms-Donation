# OpenArms Donation Platform

## Overview
**OpenArms Donation Platform** is a user-friendly web application designed to support donations for various charitable causes, with a primary focus on flood relief efforts in Bangladesh. The platform provides an intuitive interface, enabling users to easily contribute while keeping track of their donations through real-time updates and a dynamic history.

[**Live Demo**](https://ayshaurmi0.github.io/OpenArms-Donation/)

## Features
- **Responsive Design**: Optimized for mobile, tablet, and desktop using Tailwind CSS and DaisyUI, ensuring seamless access on any device.
- **Donation Cards**: Each card represents a specific cause with details about the cause and a donation input field.
- **Real-time Balance Updates**: Automatically updates donation totals and balances as users input their donations.
- **Donation History**: Tracks and displays a history of donations, showing the date and amount for each donation.
- **Modal Confirmation**: After a donation, users receive confirmation through a modal window for an enhanced experience.

## Technologies Used
- **HTML5**: Provides the structural foundation of the website.
- **Tailwind CSS**: A utility-first CSS framework for responsive and customizable designs.
- **DaisyUI**: A plugin for Tailwind CSS that offers pre-designed UI components.
- **JavaScript**: Enables dynamic content, interactivity, and real-time updates.
- **Google Fonts**: Uses the "Lexend" font for modern, clean typography.
